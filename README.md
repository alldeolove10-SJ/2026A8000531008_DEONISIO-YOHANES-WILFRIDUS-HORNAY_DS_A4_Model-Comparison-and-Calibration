# DS-A4 Model Comparison and Calibration Lab

## Package contents
- `notebooks/DS_A4_Model_Comparison_and_Calibration_Lab.ipynb`: runnable notebook entry point.
- `src/run_analysis.py`: canonical reproducible analysis script.
- `data/wdbc_sklearn_frozen.csv`: frozen local dataset (569 rows, 30 numeric predictors, binary diagnosis).
- `data/DATA_PROVENANCE.md`: source notes and local SHA-256.
- `results/`: generated metrics, paired predictions, threshold sensitivity grid, environment record.
- `figures/`: six green/pink plots.
- `report/DS_A4_Model_Comparison_and_Calibration_Report_A4_Portrait.pdf`: four-page A4 portrait report.
- `requirements.txt`: dependencies.
- `protocol.json`: frozen technical split/model settings and explicit fields that require your decision.
- `AI_use_log.md`: record AI assistance and independent verification.
- `submission_summary_draft.md`: draft summary for you to verify and edit.

## Reproduce
From the project root:
```bash
python -m pip install -r requirements.txt
python src/run_analysis.py
```
Or open the notebook and run all cells from top to bottom. The script writes generated files into `results/` and `figures/`.

## Important protocol notes
- Seed: 42; stratified 80/20 holdout; five-fold stratified CV on the training split.
- Preprocessing is inside each pipeline.
- The positive class is malignant (encoded as 1); benign is 0.
- The threshold grid is sensitivity analysis under hypothetical false-negative/false-positive cost ratios and review capacities. It is not a final threshold recommendation.
- Complete `protocol.json` fields about primary metric, minimum meaningful difference, operational cost justification, review capacity, critical-slice rationale, and the final threshold rule.
- This is a benchmark exercise, not a clinical tool. Do not use the outputs for diagnosis or treatment.

## Integrity
All included metrics and plots were generated by running the included script in the current environment. Rerun it in your own environment, verify the outputs, retain negative findings, and record any differences.


## Full notebook walkthrough

Open `notebooks/DS_A4_Model_Comparison_and_Calibration_Lab.ipynb` and use **Kernel → Restart Kernel and Run All Cells**. The notebook now contains the full workflow as separate, readable cells: dataset provenance and audit, split and pipelines, paired cross-validation, held-out test metrics, ROC and precision–recall curves, calibration curves, metric comparison, paired bootstrap uncertainty, threshold/capacity sensitivity, critical-slice analysis, and artifact export. Figures are displayed inline and saved under `figures/`; tables and paired predictions are saved under `results/`.

The included CSV is `data/wdbc_sklearn_frozen.csv`. If it is missing, the notebook attempts to reconstruct it from scikit-learn's built-in dataset loader. Change `GREEN` and `PINK` near the top to customize the plot palette.


Windows compatibility note: the Random Forest uses `n_jobs=1` to avoid Joblib physical-core detection warnings on some Windows/Anaconda setups. This does not change the model definition or the evaluation protocol; it only disables parallel execution.
